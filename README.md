# 🐍 Khóa Học Python Từ Cơ Bản Đến Nâng Cao

## 📌 Giới thiệu

Repository này lưu trữ các kiến thức, ví dụ và bài tập thực hành trong quá trình tự học lập trình Python.

Mục tiêu của dự án là củng cố kiến thức nền tảng, rèn luyện tư duy lập trình và chuẩn bị kiến thức để học **Data Analysis, Machine Learning, Computer Vision và AI**.

## 📚 Nội dung học tập

### 1. Python cơ bản
- Biến và kiểu dữ liệu
- Các toán tử trong Python
- Câu lệnh điều kiện `if`, `elif`, `else`
- Vòng lặp `for`, `while`
- Xử lý chuỗi (String)
- Danh sách (List)
- Tuple
- Set
- Dictionary

### 2. Hàm và kỹ thuật lập trình
- Khai báo và sử dụng hàm (`def`)
- Tham số và giá trị trả về (`return`)
- Lambda
- Xử lý bài toán bằng vòng lặp
- Chia chương trình thành các hàm để dễ quản lý

### 3. Lập trình hướng đối tượng (OOP)

Các bài thực hành được lưu trong thư mục `oop`.

- Class và Object
- Tính đóng gói (Encapsulation)
- Tính kế thừa (Inheritance)
- Tính trừu tượng (Abstraction)

### 4. Làm việc với tệp
- Đọc và ghi tệp
- Xử lý dữ liệu trong tệp
- Làm việc với tệp văn bản `.txt`

### 5. Cơ sở dữ liệu SQLite
- Làm quen với SQLite
- Kết nối cơ sở dữ liệu
- Tạo bảng
- Thực hành truy vấn và thao tác dữ liệu

## 🚀 Cách chạy chương trình

### Bước 1: Cài đặt Python

Tải Python tại: https://www.python.org/downloads/

### Bước 2: Tải repository về máy

Clone repository bằng lệnh:

```bash
git clone <URL_REPOSITORY>
```

Hoặc tải mã nguồn trực tiếp từ GitHub.

### Bước 3: Mở thư mục bằng VS Code

Mở Terminal tại thư mục chứa bài tập.

### Bước 4: Chạy chương trình

Ví dụ chạy bài tập chuỗi:

```bash
python chuoi.py
```

Chạy bài tập OOP:

```bash
python oop/class.py
```



*Các dấu tích thể hiện những nội dung đã bắt đầu học hoặc thực hành, không nhất thiết có nghĩa là đã thành thạo.*
